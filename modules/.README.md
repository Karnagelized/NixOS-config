# Настройка модулей


## Binds модуль
Позволяет делать кастомные бинды. Для этого необходимо добавить в `custom-keybindings` новую строку с `+1` индексом.
Далее прописывается бинд по аналогии:

```text
[org.gnome.settings-daemon.plugins.media-keys.custom-keybindings.custom1]
binding='<Super>t'
command='kgx'
name='Open Terminal'
```


## Games модуль


### AGGL
Для корректного запуска Genshin Impact в `AAGL` необходимо выставить следующие настройки в `AAGL`:
* Нажимаем на шестеренку -> Улучшения

1. Wine:
* `Синхронизация` - `Esync`. 
* `Окно без рамок` - `On`
* `Enable Winewayland` - `On`
* `Виртуальный рабочий стол` - `Off`
* `Enable timeout fix` - `On`
* `Создавать диск C:` - `On`
* `Создавать диск с папкой игры` - `g: On`

2. Игра
* `HUD` - `Нет`
* `FSR` - `Off`
* `Gamemode` - `off`
* `Gamescope` - `off`

3. FPS Unlocker
* `Включен` - `Off`
* `Задержка между перезаписями` - `5000`
